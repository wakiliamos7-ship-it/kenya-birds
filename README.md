# Birds of Kenya

A small website showcasing 10 bird species found in Kenya, built for my web development class.

## Features
- About Me section
- 10 bird cards, each with a photo, a short description, and a photo credit
- Responsive grid layout that works on phones and desktops
- Hover effects on the cards

## Built With
- HTML
- CSS (no JavaScript)

## Photo Credits
Each photo is credited under the bird it belongs to.
